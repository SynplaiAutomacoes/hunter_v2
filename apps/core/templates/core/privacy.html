Política de Privacidade

Esta política se aplica aos dados enviados pelo formulário de interesse do Sistema Hunter Auto.

Responsável e contato de privacidade

O responsável pelo tratamento dos dados desta página é {{ legal.supplier_legal_name }}, fornecedor do Hunter Auto, inscrito no CNPJ {{ legal.supplier_cnpj }}, com endereço em {{ legal.supplier_address }}. Para dúvidas ou solicitações sobre seus dados pessoais, entre em contato pelo e-mail {{ legal.privacy_email }}.

Quais dados são coletados

Nome, nome da oficina, e-mail, WhatsApp, quantidade de funcionários e faixa de faturamento informados no formulário. Também são registrados a data do envio, a página de origem, parâmetros de campanha disponíveis e o consentimento para contato.

Finalidade e consentimento

Os dados são utilizados para que a equipe comercial entre em contato por WhatsApp ou e-mail e apresente o Hunter Auto. O consentimento é solicitado de forma específica e não é marcado previamente. O formulário não realiza contratação ou pagamento.

Armazenamento e acesso

Os registros são armazenados no ambiente do Hunter Auto. Os contatos não ficam disponíveis para consulta pública na página.

Prazo de retenção

Os dados enviados pelo formulário são mantidos por {% if legal.retention_years == 2 %}dois anos{% else %}{{ legal.retention_years }} anos{% endif %} a partir da data do envio. Você pode solicitar a exclusão antes desse prazo enviando um e-mail para {{ legal.privacy_email }}.

Seus direitos

A LGPD prevê direitos de confirmação, acesso, correção e, nos casos aplicáveis, exclusão, revogação do consentimento e informação sobre compartilhamento. Para exercer esses direitos, incluindo solicitar a exclusão dos seus dados ou revogar o consentimento para contato comercial, envie sua solicitação para {{ legal.privacy_email }}.

Atualizações

Esta política poderá ser atualizada para refletir alterações nas práticas de tratamento de dados. As informações atualizadas serão disponibilizadas nesta página.
